# Ghats / Fieldnotes

An editorial trekking journal prototype for Aditya. All entries, distances, elevation figures, dates, and field notes are **demo content**, not records of actual expeditions. The two bundled photographs are generated illustrative imagery, not documentary evidence of a specific trail.

## Run
`npm install && npm run dev`

## Customize
Edit `src/data.js` for the three starter stories, replace `assets/` with your own photography, and revise the header/intro. Visitors can add their own local draft in the browser; drafts stay on that device. No account, backend, or sync. `npm run build` produces `dist/`.
